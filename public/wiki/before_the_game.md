# Знать перед игрой:
### В канале объявлений публикуются:
* Карта
* Айпи сервера
* Файл чанков Voxy

Карта размечена на **квадраты**. Также на карте указаны ангары и склады.
Установить скин на пиратке, который будут видеть другие игроки - **/skin url "<ссылка на файл скина>"**
Обновить скин без перезахода на сервер - **/skin update**

Сбор обычно в **16.00 (МСК)**.
Начало игры через **20 минут** с начала сбора. 
Перед игрой собираются команды и обсуждают стратегию.

ЗАПРЕЩЕНО:
1. Использование читов
2. Использование модов на карту
3. Использование любых иных средств, дающих преимущество
